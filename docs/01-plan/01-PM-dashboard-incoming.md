## 1. 프로젝트 개요

### 1.1 배경

㈜태웅은 중공업 단조·열처리 전문 제조업체로, 핵심 공정은 **입고 → 가열 → 단조 → 열처리 → 검사 → 출하** 순서로 진행된다. 원료 단계에서의 품질 편차가 최종 제품의 기계적 성질에 직접적인 영향을 미치며, 대형 단조품 특성상 불량 발생 시 재작업·폐기 비용이 극히 크다. 현재 공정 데이터는 분산 관리되어 실시간 의사결정이 어렵고, 원료 적합성 판단에 숙련 인력 의존도가 높다.

### 1.2 핵심 식별자

| 식별자 | 정의 | 특성 |
|--------|------|------|
| Heat No. | 제강 배치 단위 번호 | 동일 Heat에서 복수 LOT 생성 가능. 원료 추적의 최상위 키 |
| LOT 번호 | 공정 추적 단위 번호 | Heat No.에 종속. 공정별 이력, 검사 결과 연계 기준 |

### 1.3 범위 (Scope)

**포함 (In Scope)**
- AI 대시보드: 생산현황·품질현황·설비상태·출하현황 분석 화면 및 알림
- 입고배합관리: 입고등록·원자재이력조회·데이터관리·공급처품질분석·AI Agent

**제외 (Out of Scope)**
- ERP 연동 개발 (데이터 수신 인터페이스 정의까지만 포함)
- 제강 공정 자체 자동화 제어
- 모바일 앱 (웹 반응형 대응 수준까지만)
- 고객 포털 외부 접속

## 2. 모듈 1: AI 대시보드

### 2.1 생산현황분석

#### 기능 개요

**Why**: 단조·열처리 공정은 순차 의존 구조이므로 특정 공정의 지연이 전체 납기에 연쇄 영향을 준다. 관리자가 공정별 생산량과 진행률을 실시간으로 파악하지 못하면 병목 발생 후 대응이 늦어진다.

**What**: 공정별 생산량, 진행률, 사이클 타임, 병목 구간을 시각화하여 현장 관리자와 경영진이 실시간 의사결정을 내릴 수 있는 종합 생산 현황 대시보드를 제공한다.

#### 사용자 스토리

- 나는 **생산관리자**로서, **당일 공정별 진행 상태를 한눈에 파악**하기 위해, **실시간 생산 진행률 게이지와 공정 흐름 맵**을 원한다.
- 나는 **현장 반장**으로서, **내 공정이 병목 구간인지 즉시 확인**하기 위해, **병목 공정 자동 하이라이트 및 경고 알림 기능**을 원한다.
- 나는 **경영진**으로서, **주간·월간 생산 실적을 목표 대비 분석**하기 위해, **기간별 생산량 추이 차트와 목표 달성률 KPI 카드**를 원한다.
- 나는 **생산계획 담당자**로서, **LOT별 공정 완료 예정 시각을 예측**하기 위해, **AI 기반 공정 완료 예측 정보**를 원한다.

#### 화면 구성 설명

**메인 영역 구성**
- 상단 KPI 카드 (4개): 당일 생산량, 목표 달성률, 평균 사이클 타임, 가동률
- 중앙 공정 흐름 맵: 입고→가열→단조→열처리→검사→출하 노드 시각화, 노드별 재공품 수량·진행률 표시, 병목 노드는 주황/적색 강조
- 하단 좌측 - 공정별 생산량 막대 차트 (시간대별 분해 가능)
- 하단 우측 - LOT별 진행 현황 테이블

**필터/검색 조건**
- 기간 선택 (당일 / 주간 / 월간 / 사용자 지정)
- 공정 선택 (전체 / 개별 공정)
- 제품군 분류
- Heat No. / LOT 번호 검색

**LOT 현황 테이블 컬럼**
- LOT 번호, Heat No., 제품명, 현재 공정, 진행률(%), 투입 시각, 예상 완료 시각, 지연 여부

**액션 버튼**
- [상세 보기] - LOT 드릴다운
- [알림 설정] - 병목 임계값 설정
- [Excel 내보내기]
- [새로고침] (기본 30초 자동 갱신)

#### 비즈니스 로직

**핵심 계산 공식**
```
가동률 = (실제 가동시간 / 계획 가동시간) × 100 (%)
목표 달성률 = (실제 생산량 / 계획 생산량) × 100 (%)
사이클 타임 = 공정 완료 시각 - 공정 투입 시각 (분)
병목 지수 = 해당 공정 재공품 수 / 전일 평균 재공품 수
```

**알림 트리거 조건**
- 병목 지수 > 1.5 → 주의 (노란색)
- 병목 지수 > 2.0 → 경고 (주황색, 담당자 SMS/이메일)
- 가동률 < 70% → 경고 알림
- 목표 달성률 < 80% (일일 기준 오후 3시 이후) → 조기 경보

**AI 예측 로직**
- 과거 LOT별 공정 소요 시간 데이터 학습 (최소 6개월)
- 현재 재공품 수, 설비 가동 상태, 작업자 수 고려
- 예상 완료 시각 = 현재 시각 + AI 예측 잔여 시간 (신뢰도 표시 포함)

#### 데이터 입출력 정의

**입력 데이터**
- MES 공정 실적 DB: 투입/완료 시각, 작업자, 설비 ID
- 생산계획 DB: 당일/주간 계획 수량, LOT별 목표 공정
- 설비 상태 DB: 가동/정지 이벤트, 비계획 정지 사유

**출력 데이터**
- 실시간 대시보드 렌더링 (웹소켓 or 30초 폴링)
- 알림 이벤트 → 알림 서비스 (SMS, 이메일, 화면 팝업)
- 생산 실적 리포트 → PDF/Excel 다운로드

**연동 시스템**
- ERP (생산계획 수신)
- 공정 MES (실적 수신)
- 알림 서비스 (발신)

#### 수용 기준 (Acceptance Criteria)

1. 화면 로딩 후 30초 이내 자동 갱신되며, 최근 실적이 KPI 카드에 반영된다.
2. 병목 지수 > 2.0인 공정 노드는 적색으로 강조 표시되고 담당자에게 알림이 발송된다.
3. LOT 번호 검색 시 해당 LOT의 현재 공정, 진행률, 예상 완료 시각이 3초 이내 표시된다.
4. 기간 필터 변경 시 차트와 테이블 데이터가 선택 기간에 맞게 즉시 재조회된다.
5. AI 예측 완료 시각은 신뢰도(%) 값과 함께 표시되어야 하며, 신뢰도 미달 시 "예측 불가" 표시한다.

#### 우선순위 (MoSCoW)

| 기능 | 우선순위 |
|------|---------|
| 실시간 공정 흐름 맵 | Must Have |
| KPI 카드 (가동률·달성률) | Must Have |
| LOT 현황 테이블 | Must Have |
| 병목 알림 | Must Have |
| AI 완료 시각 예측 | Should Have |
| Excel 내보내기 | Should Have |
| 기간별 추이 차트 | Should Have |
| 모바일 반응형 대시보드 | Could Have |

### 2.2 품질현황분석

#### 기능 개요

**Why**: 단조 제품의 최종 합격 여부는 인장강도·항복강도·연신율·충격치 등 기계적 성질 시험과 UT 초음파 비파괴검사(NDT) 결과로 결정된다. 이 데이터가 분산되어 있으면 결함 패턴 인식이 늦어져 동일 원인에 의한 불량이 반복된다.

**What**: 기계적 성질 검사 결과, NDT 결과, 결함 발생 현황을 통합하여 공정·Heat No.·원료 공급사별 품질 수준을 분석하고, 품질 트렌드 이상 징후를 조기 감지한다.

#### 사용자 스토리

- 나는 **품질관리자**로서, **Heat No.별 기계적 성질 합격률 추이를 파악**하기 위해, **Heat No. 기준 시험 결과 집계 차트**를 원한다.
- 나는 **검사원**으로서, **당일 NDT 검사 대기 및 결과 현황을 관리**하기 위해, **NDT 검사 현황 리스트와 결과 입력 기능**을 원한다.
- 나는 **품질관리자**로서, **불량 패턴을 공정 단계별로 분석**하기 위해, **결함 유형 × 공정 단계 히트맵**을 원한다.
- 나는 **경영진**으로서, **월간 품질 KPI를 보고**하기 위해, **불량률, 합격률, 재작업률 KPI 요약 카드**를 원한다.

#### 화면 구성 설명

**메인 영역 구성**
- 상단 품질 KPI 카드: 종합 합격률, 불량률, NDT 불합격률, 재작업률
- 중앙 좌측 - 기계적 성질 산점도 (인장강도/항복강도 × 기준선 표시)
- 중앙 우측 - 결함 유형별 파레토 차트
- 하단 - 품질 이력 테이블 (Heat No.·LOT 기준)

**필터/검색 조건**
- 기간, 공정, 제품군, Heat No., LOT 번호, 공급사, 검사 유형 (기계적 성질 / NDT / 외관)

**품질 이력 테이블 컬럼**
- LOT 번호, Heat No., 제품명, 검사 유형, 인장강도, 항복강도, 연신율, 충격치, NDT 결과, 판정 (합격/불합격/조건부), 검사일, 검사원

**액션 버튼**
- [결과 입력] - 검사 결과 신규 등록
- [불합격 상세] - 결함 내용 드릴다운
- [트렌드 분석] - 시계열 품질 추이 차트 전환
- [리포트 생성]

#### 비즈니스 로직

**핵심 계산 공식**
```
합격률 = (합격 LOT 수 / 전체 검사 LOT 수) × 100 (%)
불량률 = (불합격 LOT 수 / 전체 검사 LOT 수) × 100 (%)
재작업률 = (재작업 건수 / 전체 완성 건수) × 100 (%)
Cpk = min((USL - 평균) / (3σ), (평균 - LSL) / (3σ))  -- 공정능력지수
```

**알림 트리거 조건**
- 불량률 > 3% (주간 기준) → 품질 경고 알림
- 동일 Heat No.에서 2건 이상 불합격 → 즉시 알림 + 해당 Heat 잔여 LOT 추가 검사 권고
- 특정 기계적 성질 항목 Cpk < 1.33 → 공정 이상 징후 알림
- NDT 불합격 LOT 발생 시 → 즉시 검사팀장 알림

**품질 이상 패턴 AI 감지**
- 이동 평균 대비 ±2σ 이탈 시 이상 징후 마킹
- 동일 공급사 원료 기반 LOT에서 불량 클러스터 발생 시 공급사 연계 이상 판정

#### 데이터 입출력 정의

**입력 데이터**
- 검사 실적 DB: 기계적 성질 시험 결과 (인장강도, 항복강도, 연신율, 충격치)
- NDT 결과 DB: UT 검사 결과, 결함 위치·크기·유형
- 공정 MES: 공정 이력 (열처리 온도, 단조 하중 등 연계 파라미터)

**출력 데이터**
- 품질 분석 대시보드 화면
- 불량 알림 이벤트 → 알림 서비스
- 품질 이상 징후 → AI 대시보드 통합 알림 피드
- 월간 품질 리포트 → PDF

**연동 시스템**
- LIMS (Laboratory Information Management System) 또는 검사 DB
- 공정 MES
- 알림 서비스

#### 수용 기준 (Acceptance Criteria)

1. Heat No. 검색 시 해당 Heat에 속한 전체 LOT의 기계적 성질 결과가 테이블과 산점도에 함께 표시된다.
2. 불량률이 3%를 초과하면 KPI 카드 색상이 적색으로 변경되고 품질관리자에게 알림이 발송된다.
3. 동일 Heat No.에서 2건 이상 불합격 시 시스템이 자동으로 해당 Heat 잔여 LOT에 "추가 검사 필요" 플래그를 설정한다.
4. NDT 결과와 기계적 성질 결과가 동일 LOT 기준으로 단일 화면에서 조회된다.
5. 파레토 차트는 상위 3개 결함 유형을 누적 비율과 함께 표시한다.

|------|---------|

| 품질 KPI 카드 | Must Have |
| 불량률 초과 알림 | Must Have |
| 결함 유형 파레토 차트 | Should Have |

| 결함 위치 시각화 (제품 도면 오버레이) | Could Have |

### 2.3 설비상태 모니터링

#### 기능 개요

**Why**: 가열로·열처리로는 단조 공정의 핵심 설비로, 온도 프로파일 이탈이나 설비 이상은 제품 품질에 직접 영향을 미친다. 예방 정비 없이 갑작스러운 설비 고장이 발생하면 진행 중인 배치 전체가 스크랩될 수 있다.

**What**: 가열로·열처리로의 온도·전류·진동 센서 데이터를 실시간 수집하여 이상 징후를 AI로 조기 감지하고, 설비별 위험도를 시각화하여 예방 정비 의사결정을 지원한다.

#### 사용자 스토리

- 나는 **설비 담당자**로서, **가열로 온도 편차를 실시간으로 감지**하기 위해, **설비별 센서 데이터 실시간 트렌드 차트**를 원한다.
- 나는 **설비 관리자**로서, **다음 주 정비 계획 수립을 위해 위험도가 높은 설비를 파악**하기 위해, **설비별 AI 위험도 점수 랭킹 화면**을 원한다.
- 나는 **현장 운전원**으로서, **설비 이상 발생 시 즉시 인지**하기 위해, **이상 감지 시 경보음 및 팝업 알림 기능**을 원한다.
- 나는 **생산관리자**로서, **설비 가동 이력과 고장 빈도를 분석**하기 위해, **설비별 가동·정지·고장 이력 캘린더 뷰**를 원한다.

#### 화면 구성 설명

**메인 영역 구성**
- 상단 설비 상태 요약 카드: 전체 설비 수, 정상 가동, 점검 중, 고장, 경고 건수
- 중앙 설비 배치도 (공장 레이아웃 기반): 각 설비를 색상 코드(녹색/노란색/주황색/적색)로 상태 표시
- 우측 패널 - 선택 설비 센서 실시간 차트 (온도, 전류, 진동 각각 표시)
- 하단 - AI 위험도 랭킹 테이블

**필터/검색 조건**
- 설비 유형 (가열로 / 열처리로 / 단조 프레스 / 기타)
- 상태 필터 (전체 / 정상 / 경고 / 고장)
- 설비 ID / 설비명 검색

**AI 위험도 랭킹 테이블 컬럼**
- 설비 ID, 설비명, 유형, AI 위험도 점수 (0~100), 위험 등급 (낮음/중간/높음/위험), 주요 이상 징후, 권장 조치, 마지막 정비일

**액션 버튼**
- [정비 요청 등록] - 위험 설비 정비 작업 지시 생성
- [알림 임계값 설정]
- [센서 이력 조회] - 기간별 상세 센서 데이터
- [정비 이력 보기]

#### 비즈니스 로직

**핵심 계산 공식**
```
설비 가동률 = (가동 시간 / 계획 가동 시간) × 100 (%)
MTBF = 총 가동 시간 / 고장 횟수 (평균 고장 간격, 시간)
MTTR = 총 수리 시간 / 고장 횟수 (평균 수리 시간, 시간)
AI 위험도 점수 = f(온도 이탈 빈도, 진동 이상값, 전류 급변, MTBF 잔여 수명 추정)
```

**알림 트리거 조건**
- 온도 설정값 대비 ±15°C 초과 편차 지속 5분 → 경고
- 온도 설정값 대비 ±30°C 초과 편차 지속 2분 → 긴급 경보 (운전 중단 검토)
- 진동값이 기준치 200% 초과 → 경고
- AI 위험도 점수 ≥ 70 → 설비 담당자 알림
- AI 위험도 점수 ≥ 90 → 즉시 경보 + 생산관리자 알림

**AI 이상 감지 로직**
- 입력: 실시간 센서 데이터 (온도, 전류, 진동), 과거 고장 이력
- 모델: 시계열 이상 감지 (LSTM Autoencoder 또는 Isolation Forest)
- 출력: 이상 징후 유형 레이블, 이상 확신도(%), 예상 고장 시점 (가능한 경우)
- 신뢰도 < 60%인 경우 "데이터 부족 - 모니터링 지속" 메시지 표시

#### 데이터 입출력 정의

**입력 데이터**
- IoT 센서 게이트웨이: 온도, 전류, 진동 센서 (수집 주기: 1분 이내)
- 설비 관리 DB: 정비 이력, 설비 사양, 마지막 정비일
- 운전 이력 DB: 가동·정지·고장 이벤트 로그

**출력 데이터**
- 실시간 설비 상태 화면
- 이상 징후 알림 → 알림 서비스
- AI 위험도 점수 → AI 대시보드 통합 피드
- 정비 요청 데이터 → 설비 관리 시스템

**연동 시스템**
- IoT 센서 플랫폼 (MQTT/OPC-UA)
- 설비 관리 시스템 (CMMS)
- 알림 서비스

#### 수용 기준 (Acceptance Criteria)

1. 센서 데이터는 최대 1분 지연 이내로 화면에 반영되어야 한다.
2. 온도 이탈 경고 발생 시 해당 설비 아이콘이 주황색으로 변경되고 운전원에게 팝업 알림이 표시된다.
3. AI 위험도 점수는 0~100 범위의 수치와 위험 등급 레이블로 표시되며, 산출 근거(주요 이상 징후 항목)가 함께 제공된다.
4. 설비 배치도에서 임의 설비 클릭 시 해당 설비의 센서 실시간 차트가 3초 이내 표시된다.
5. 정비 요청 등록 버튼 클릭 시 설비 ID, 이상 내용, 우선순위가 자동 입력된 정비 지시 양식이 생성된다.

#### 우선순위 (MoSCoW)

| 기능 | 우선순위 |
|------|---------|
| 실시간 센서 트렌드 차트 | Must Have |
| 온도 이탈 알림 | Must Have |
| 설비 상태 배치도 | Must Have |
| AI 위험도 점수 랭킹 | Should Have |
| MTBF/MTTR 분석 | Should Have |
| 예방 정비 스케줄 제안 | Could Have |
| 3D 설비 모델 시각화 | Won't Have |

### 2.4 출하현황분석

#### 기능 개요

**Why**: 대형 단조품은 납기 준수가 고객 신뢰도에 직결되며, 납기 지연 시 고액의 지체상금이 발생한다. 출하 준비 단계에서 납기 리스크를 사전에 파악하지 못하면 대응이 불가능하다.

**What**: 출하 LOT 현황, 납기 준수율, 고객별 출하 현황을 분석하고, AI 기반 납기 리스크를 사전에 감지하여 선제적 대응이 가능하도록 지원한다.

#### 사용자 스토리

- 나는 **영업/물류 담당자**로서, **이번 주 출하 예정 LOT와 납기 준수 가능 여부를 확인**하기 위해, **납기 기준 정렬 출하 예정 리스트와 위험 LOT 하이라이트**를 원한다.
- 나는 **생산관리자**로서, **납기 지연 위험 LOT를 조기에 파악하여 생산 우선순위를 조정**하기 위해, **AI 납기 리스크 예측 결과와 우선순위 권고 기능**을 원한다.
- 나는 **경영진**으로서, **고객별 납기 준수율 현황을 파악하여 고객 관계 관리에 활용**하기 위해, **고객별 납기 준수율 집계 차트**를 원한다.
- 나는 **품질관리자**로서, **출하 LOT의 최종 검사 완료 여부를 확인**하기 위해, **출하 게이트 체크리스트 (검사 완료, 문서 완비 여부)**를 원한다.

#### 화면 구성 설명

**메인 영역 구성**
- 상단 출하 KPI 카드: 이번 달 납기 준수율, 출하 완료 건수, 납기 지연 건수, 출하 예정 건수
- 중앙 좌측 - 납기 달력 뷰: 날짜별 출하 예정 LOT 수 표시, 리스크 수준별 색상 코드
- 중앙 우측 - 납기 리스크 TOP 10 테이블 (AI 예측 기반)
- 하단 - 고객별 납기 준수율 막대 차트

**필터/검색 조건**
- 기간, 고객사, 납기 상태 (예정/완료/지연/위험), LOT 번호, 제품명

**출하 현황 테이블 컬럼**
- LOT 번호, Heat No., 제품명, 고객사, 납기 일자, 현재 공정, 예상 완료일, 납기까지 잔여일, AI 리스크 점수, 리스크 등급, 검사 완료 여부

**액션 버튼**
- [출하 확정]
- [납기 연장 요청]
- [생산 우선순위 조정 요청]
- [고객 알림 발송]

#### 비즈니스 로직

**핵심 계산 공식**
```
납기 준수율 = (납기 내 출하 건수 / 전체 출하 건수) × 100 (%)
납기 여유 일수 = 납기 일자 - 예상 완료일 (음수이면 지연 예측)
AI 납기 리스크 점수 = f(납기 여유 일수, 현재 공정 진행률, 설비 상태, 유사 LOT 과거 이탈 빈도)
```

**알림 트리거 조건**
- 납기 여유 일수 ≤ 3일이고 공정 완료율 < 80% → 납기 리스크 경고
- AI 납기 리스크 점수 ≥ 70 → 영업/생산관리자 알림
- 납기 초과 확정 시 → 즉시 담당 영업 알림

**AI 납기 리스크 예측 로직**
- 입력: 현재 공정 진행률, 잔여 공정 예상 소요 시간, 설비 위험도, 대기 LOT 수
- 출력: 리스크 점수 (0~100), 리스크 등급, 예상 완료 일자, 신뢰도(%)
- 신뢰도 < 60%인 경우 "예측 정확도 낮음" 배지 표시

#### 데이터 입출력 정의

**입력 데이터**
- ERP 수주 DB: 납기 일자, 고객사, 수량, 제품 규격
- 공정 MES: LOT별 현재 공정, 진행률, 잔여 공정 목록
- AI 생산 예측 엔진: 공정별 예상 소요 시간
- 검사 DB: 최종 검사 완료 여부

**출력 데이터**
- 출하 현황 대시보드 화면
- 납기 리스크 알림 → 알림 서비스
- 출하 게이트 체크리스트 → 품질·물류 담당자

**연동 시스템**
- ERP (수주·납기 수신)
- 공정 MES
- 알림 서비스

#### 수용 기준 (Acceptance Criteria)

1. 납기 달력 뷰에서 당일 출하 예정 LOT가 날짜 셀 내에 표시되며, 클릭 시 상세 정보가 즉시 조회된다.
2. AI 납기 리스크 점수가 70 이상인 LOT는 납기 리스크 TOP 10 테이블에 자동 포함되고 적색으로 강조 표시된다.
3. 납기 준수율 KPI 카드는 이번 달 기준 자동 집계되며, 전월 대비 증감 화살표가 함께 표시된다.
4. 출하 확정 처리 시 검사 완료 및 필수 서류 완비 여부를 시스템이 자동 검증하고, 미완료 항목이 있으면 출하 확정이 차단된다.
5. 고객별 납기 준수율 차트는 최근 6개월 데이터를 기본으로 표시한다.

#### 우선순위 (MoSCoW)

| 기능 | 우선순위 |
|------|---------|
| 출하 예정 LOT 리스트 | Must Have |
| 납기 준수율 KPI | Must Have |
| 납기 리스크 알림 | Must Have |
| AI 납기 리스크 점수 | Should Have |
| 납기 달력 뷰 | Should Have |
| 고객별 준수율 차트 | Should Have |
| 출하 게이트 체크리스트 자동화 | Should Have |
| 고객 포털 연동 알림 | Won't Have |

## 3. 모듈 2: 입고배합관리

### 3.1 입고관리

#### 기능 개요

**Why**: 단조 원료(빌렛, 블룸, 잉곳)는 Heat No. 기준으로 제강사에서 제조되며, 입고 시 성분 분석·치수 검수가 이루어진다. 이 정보가 정확히 등록되지 않으면 이후 공정 전체의 추적성(traceability)이 무너진다.

**What**: 원료 입고 시 Heat No. 기준 등록·검수·LOT 생성 프로세스를 디지털화하고, 제강 공정 데이터와 자동 연계하여 원료 추적성의 기반을 구축한다.

#### 사용자 스토리

- 나는 **입고 담당자**로서, **입고된 원료를 Heat No. 기준으로 신속하게 등록**하기 위해, **바코드/QR 스캔 기반 입고 등록 기능**을 원한다.
- 나는 **품질 검수원**으로서, **입고 원료의 성분 분석 결과와 치수 검수 결과를 입력·관리**하기 위해, **입고 검수 결과 입력 폼과 합격/불합격 판정 기능**을 원한다.
- 나는 **생산계획 담당자**로서, **입고된 원료가 어떤 수주 제품에 배합될지 계획**하기 위해, **Heat No.에서 LOT를 생성하고 생산 오더에 연계하는 기능**을 원한다.
- 나는 **품질관리자**로서, **특정 Heat No.의 원료가 어느 공정까지 투입되었는지 추적**하기 위해, **Heat No. 기준 공정 투입 이력 조회 기능**을 원한다.

#### 화면 구성 설명

**메인 영역 구성**
- 입고 등록 폼 (상단): Heat No., 공급사, 강종, 규격, 수량, 입고 일자, 원산지, 성분 분석서 첨부
- 검수 현황 리스트 (중앙): 검수 대기·완료·반품 상태별 탭 구분
- LOT 생성 패널 (하단): Heat No. 선택 → LOT 분할 수 입력 → LOT 번호 자동 채번

**필터/검색 조건**
- 기간, 공급사, 강종, Heat No., 검수 상태, LOT 생성 여부

**입고 현황 테이블 컬럼**
- Heat No., 공급사, 강종, 규격, 수량 (ton), 입고 일자, 검수 상태, LOT 수, 성분 분석 첨부 여부, 등록자

**액션 버튼**
- [신규 입고 등록]
- [검수 결과 입력]
- [LOT 생성]
- [반품 처리]
- [성분 분석서 보기]

#### 비즈니스 로직

**핵심 계산 공식**
```
LOT 번호 채번 규칙: [연도 2자리][월 2자리][Heat No.][순번 2자리]
  예) 2605-HT12345-01

입고 합격 판정: 성분 분석 결과가 강종 규격 기준(C, Si, Mn, P, S 등) 전 항목 허용 범위 내 → 합격
치수 합격 판정: 실측 치수가 발주 규격 ±허용 공차 이내 → 합격
```

**알림 트리거 조건**
- 성분 분석 결과 1개 이상 항목 기준 초과 → 불합격 처리 + 품질관리자 알림
- 입고 후 48시간 이내 검수 미완료 시 → 담당자 알림
- Heat No. 중복 입고 감지 시 → 경고 팝업 (오입력 방지)

#### 데이터 입출력 정의

**입력 데이터**
- 수작업 입력 또는 바코드/QR 스캔: Heat No., 공급사, 강종, 수량
- 업로드 파일: 성분 분석서 (PDF/Excel), 밀 시트(Mill Sheet)
- ERP 발주 DB: 발주 내역 (자동 매핑을 위해 조회)

**출력 데이터**
- 입고 등록 DB: Heat No. 마스터 생성
- LOT 생성 DB: LOT 번호 생성 및 Heat No. 연계
- 원자재 재고 DB: 입고 수량 반영
- 알림 서비스: 불합격·미검수 알림

**연동 시스템**
- ERP (발주 대비 입고 대사)
- 원자재 재고 관리
- 공정 MES (LOT 정보 전달)

#### 수용 기준 (Acceptance Criteria)

1. Heat No. 입력 후 [LOT 생성] 버튼 클릭 시 LOT 번호가 채번 규칙에 따라 자동 생성되고, 생성된 LOT가 공정 MES에 즉시 전달된다.
2. 성분 분석 결과 입력 시 강종별 규격 기준값이 자동으로 표시되고, 기준 초과 항목은 적색으로 강조되며 불합격 판정이 자동 부여된다.
3. 동일 Heat No.가 이미 등록된 상태에서 중복 입력 시 경고 팝업이 표시되고 저장이 차단된다.
4. 입고 등록 완료 후 원자재 재고 DB에 해당 Heat No.의 수량이 즉시 반영된다.
5. Heat No. 기준 검색 시 해당 Heat에서 생성된 전체 LOT 목록이 공정 투입 상태와 함께 표시된다.

### 3.2 원자재이력조회

#### 기능 개요

**Why**: 출하된 제품에서 품질 문제가 발생했을 때 원료 단계까지 역추적이 가능해야 한다. 또한 동일 공급사 동일 강종의 과거 품질 이력이 현재 입고 판단에 참고 자료가 되어야 한다.

**What**: Heat No.·LOT 번호·공급사·강종 기준으로 원자재의 성분 이력, 공정 투입 이력, 과거 품질 문제 이력을 통합 조회할 수 있는 원자재 이력 추적 시스템을 제공한다.

#### 사용자 스토리

- 나는 **품질관리자**로서, **현장 클레임 접수 시 문제 제품의 원료를 역추적**하기 위해, **제품 LOT 번호에서 Heat No.까지 역방향 추적 기능**을 원한다.
- 나는 **입고 담당자**로서, **신규 입고 원료와 동일 공급사의 과거 품질 이력을 참고**하기 위해, **공급사별 과거 성분 분석 결과 및 품질 문제 이력 조회 기능**을 원한다.
- 나는 **연구개발 담당자**로서, **특정 강종의 성분 편차와 기계적 성질 상관관계를 분석**하기 위해, **강종별 성분 데이터와 최종 기계적 성질 연계 조회 기능**을 원한다.
- 나는 **경영진**으로서, **과거 품질 문제의 원인 원료를 특정하여 공급사 평가에 반영**하기 위해, **품질 문제 발생 LOT의 원료 정보 일괄 조회 기능**을 원한다.

#### 화면 구성 설명

**메인 영역 구성**
- 이력 추적 검색 패널 (상단): Heat No. / LOT 번호 / 공급사 / 강종 / 기간 검색
- 이력 트리 뷰 (중앙 좌측): Heat No. → LOT 목록 → 공정 단계 펼침 트리
- 상세 정보 패널 (중앙 우측): 선택된 노드의 상세 데이터 (성분, 검사 결과, 공정 조건)
- 품질 문제 이력 섹션 (하단): 해당 Heat/LOT 연관 클레임·불합격 이력

**필터/검색 조건**
- Heat No., LOT 번호, 공급사, 강종, 성분 원소 범위 검색, 기간

**이력 조회 테이블 컬럼**
- Heat No., 입고 일자, 공급사, 강종, 주요 성분 (C/Si/Mn), 연계 LOT 수, 과거 품질 문제 건수, 마지막 문제 발생일

**액션 버튼**
- [전체 이력 다운로드] (Excel/PDF)
- [품질 문제 등록]
- [AI Agent에 문의] → 3.5 입고 AI Agent 연계

#### 비즈니스 로직

**핵심 계산 공식**
```
품질 문제 발생률 (공급사별) = 품질 문제 발생 Heat 수 / 전체 입고 Heat 수 × 100 (%)
성분 편차 = (실측값 - 규격 중간값) / 규격 허용 공차 × 100 (%)
```

**알림 트리거 조건**
- 조회된 Heat No.의 과거 품질 문제 이력이 2건 이상 존재 시 → 경고 배지 표시
- 동일 공급사 동일 강종에서 최근 6개월 내 품질 문제 발생 시 → 신규 입고 검수 시 경고 표시

#### 데이터 입출력 정의

**입력 데이터**
- 입고 DB: Heat No., 성분 분석 데이터
- 공정 MES DB: LOT별 공정 이력
- 검사 DB: 기계적 성질, NDT 결과
- 클레임/품질 문제 DB: 불합격·클레임 이력

**출력 데이터**
- 이력 조회 화면 렌더링
- Excel/PDF 이력 보고서 다운로드
- AI Agent 문의 컨텍스트 전달

**연동 시스템**
- 입고 DB, 공정 MES, 검사 DB, 클레임 DB (내부 통합 조회)

#### 수용 기준 (Acceptance Criteria)

1. LOT 번호 입력 시 해당 LOT의 원료 Heat No., 공급사, 성분 분석 결과, 공정 이력, 검사 결과가 단일 화면에서 조회된다.
2. 이력 트리 뷰에서 Heat No. 노드를 펼치면 파생된 전체 LOT 목록과 각 LOT의 현재 상태가 표시된다.
3. 과거 품질 문제가 있는 Heat No. 조회 시 화면 상단에 경고 배너가 표시되고 품질 문제 건수가 명시된다.
4. 이력 다운로드 기능은 조회된 결과 전체를 Excel 형식으로 5초 이내에 생성하여 제공한다.
5. 공급사 기준 검색 시 해당 공급사의 전체 입고 Heat 목록과 품질 문제 발생률이 요약 섹션에 표시된다.

### 3.3 입고데이터관리

#### 기능 개요

**Why**: AI 모델의 예측 정확도는 학습 데이터의 품질에 비례한다. 입고 데이터의 오입력, 누락, 형식 불일치는 AI 학습 데이터를 오염시켜 모든 AI 기능의 신뢰성을 저하시킨다.

**What**: 입고 데이터의 완전성·일관성·정확성을 자동 검증하고, AI 학습용 데이터셋 품질 기준을 충족하도록 데이터를 관리한다.

#### 사용자 스토리

- 나는 **데이터 관리자**로서, **입력된 입고 데이터의 오류와 누락을 자동으로 감지**하기 위해, **데이터 정합성 자동 검증 기능과 오류 리포트**를 원한다.
- 나는 **AI 개발 담당자**로서, **학습 데이터의 품질 수준을 지속적으로 모니터링**하기 위해, **데이터 품질 점수 대시보드와 이상 데이터 필터링 기능**을 원한다.
- 나는 **입고 담당자**로서, **과거 잘못 입력된 데이터를 수정하고 수정 이력을 남기기**위해, **데이터 수정 기능과 변경 이력 감사 로그**를 원한다.

#### 화면 구성 설명

**메인 영역 구성**
- 데이터 품질 KPI 카드: 완전성(%), 일관성(%), 정확성(%), 전체 품질 점수
- 오류 데이터 목록 테이블: 오류 유형·대상 레코드·권장 조치 표시
- 데이터 수정 인터페이스: 오류 레코드 클릭 → 인라인 수정 폼

**비즈니스 로직 - 데이터 검증 규칙**
```
완전성 검증: 필수 입력 항목 (Heat No., 공급사, 강종, 수량, 입고 일자) 누락 여부
범위 검증: 성분 값이 해당 강종 이론 범위 내에 있는지 확인 (예: C 함량 0% ~ 3% 범위)
일관성 검증: 동일 Heat No.에 대해 공급사·강종 정보가 모든 레코드에서 일치하는지 확인
중복 검증: Heat No. + 입고 일자 기준 중복 레코드 감지
형식 검증: 날짜 형식 (YYYY-MM-DD), 수치 데이터 형식 검증
```

**알림 트리거 조건**
- 데이터 품질 점수 < 95% → 데이터 관리자 알림
- 신규 입고 데이터 정합성 검증 실패 건수 > 5건/일 → 경고

#### 수용 기준 (Acceptance Criteria)

1. 신규 입고 데이터 저장 시 정합성 검증이 자동 실행되고, 오류 항목은 저장 전 경고 팝업으로 표시된다.
2. 데이터 수정 시 수정 전·후 값, 수정자, 수정 일시가 감사 로그에 자동 기록되고 조회 가능하다.
3. 데이터 품질 KPI 카드는 전체 입고 데이터 기준 완전성·일관성·정확성을 매일 자동 집계한다.
4. AI 학습 데이터 품질 기준 (완전성 98% 이상, 정확성 97% 이상)을 충족하는 데이터만 학습 파이프라인으로 전달된다.

### 3.4 공급처품질분석

#### 기능 개요

**Why**: 원료 공급사의 품질 편차는 단조 제품 불량률과 직결된다. 공급사별 성분 안정성, 납기 신뢰도, 과거 품질 문제 빈도를 객관적으로 분석해야 전략적 구매 의사결정이 가능하다.

**What**: 공급사별 품질 수준(성분 안정성, 불량률), 납기 신뢰도, 클레임 발생률을 종합 점수로 산출하여 공급사 평가 및 구매 전략 수립을 지원한다.

#### 사용자 스토리

- 나는 **구매 담당자**로서, **어떤 공급사의 원료가 가장 안정적인 품질을 제공하는지 비교**하기 위해, **공급사별 종합 품질 점수 랭킹 화면**을 원한다.
- 나는 **품질관리자**로서, **특정 공급사의 품질 수준이 최근 악화되고 있는지 추이를 파악**하기 위해, **공급사별 월별 품질 점수 추이 차트**를 원한다.
- 나는 **경영진**으로서, **공급사 다변화 또는 교체 의사결정을 위한 객관적 근거**를 위해, **공급사 종합 평가 리포트 생성 기능**을 원한다.
- 나는 **구매 담당자**로서, **신규 발주 시 추천 공급사를 빠르게 파악**하기 위해, **강종별 추천 공급사 AI 제안 기능**을 원한다.

#### 화면 구성 설명

**메인 영역 구성**
- 공급사 랭킹 테이블 (상단): 종합 점수 기준 정렬
- 공급사 상세 분석 패널 (하단 좌측): 선택 공급사의 성분 안정성 박스 플롯, 납기 분포 차트
- 비교 분석 (하단 우측): 선택한 2~3개 공급사 레이더 차트 비교

**공급사 랭킹 테이블 컬럼**
- 공급사명, 주요 취급 강종, 총 입고 Heat 수, 성분 합격률(%), 납기 준수율(%), 클레임 발생률(%), 종합 품질 점수, 등급 (A/B/C/D), 추천 여부

**비즈니스 로직**
```
종합 품질 점수 = 성분 합격률 × 0.4 + 납기 준수율 × 0.3 + (100 - 클레임 발생률) × 0.3
성분 안정성 지수 = 1 - (성분 표준편차 / 규격 허용 공차)
납기 신뢰도 = (납기 내 입고 건수 / 전체 발주 건수) × 100 (%)
```

**알림 트리거 조건**
- 공급사 종합 점수 < 60 → 구매 담당자 주의 알림
- 특정 공급사의 최근 3개월 클레임 발생률 > 5% → 경고 + 공급사 평가 재검토 권고

#### 수용 기준 (Acceptance Criteria)

1. 공급사 랭킹은 종합 품질 점수 기준으로 내림차순 정렬되어 표시되며, 가중치 설정을 관리자가 변경할 수 있다.
2. 공급사 비교 분석 기능은 최대 3개 공급사를 선택하여 레이더 차트로 시각화한다.
3. 공급사 평가 리포트는 선택 기간의 전체 입고 데이터를 기반으로 자동 생성되며 PDF로 다운로드된다.

5. 월별 품질 점수 추이 차트는 최근 12개월 데이터를 기본으로 표시한다.

### 3.5 입고 AI Agent

#### 기능 개요

**Why**: 숙련 검수 인력의 경험적 판단에 의존하던 원료 적합성 평가를 표준화하고, 신규 인력도 일관된 판단을 내릴 수 있도록 지원해야 한다. 또한 복잡한 배합 조건 계산을 자동화하여 의사결정 속도를 높인다.

**What**: 자연어 질의 기반으로 원료 품질·이력·적합성을 판단하고, 배합 조건을 추천하며, 제강 투입 여부를 지원하는 AI Agent를 제공한다. 모든 판단 결과에는 신뢰도(confidence) 점수와 근거가 함께 제공된다.

#### 사용자 스토리

- 나는 **입고 담당자**로서, **신규 입고 Heat No.의 성분이 특정 제품 제조에 적합한지 즉시 확인**하기 위해, **자연어 질의 기반 원료 적합성 판단 AI Agent**를 원한다.
- 나는 **생산 계획 담당자**로서, **여러 Heat No.를 혼합할 때 최적 배합 비율 추천**을 받기 위해, **배합 조건 최적화 AI 추천 기능**을 원한다.
- 나는 **품질관리자**로서, **AI Agent의 판단 근거를 이해하고 최종 결정에 활용**하기 위해, **AI 판단 결과의 신뢰도 점수, 근거 데이터, 참고 이력 제시 기능**을 원한다.
- 나는 **현장 담당자**로서, **복잡한 메뉴 탐색 없이 원하는 정보를 빠르게 조회**하기 위해, **채팅 인터페이스 기반 자연어 데이터 조회 기능**을 원한다.

#### 화면 구성 설명

**메인 영역 구성**
- 채팅 인터페이스 (중앙): 자연어 입력창, 대화 히스토리 표시
- AI 응답 패널: 텍스트 응답 + 구조화된 데이터 카드 (표, 차트 임베드)
- 참조 데이터 패널 (우측): AI가 참조한 데이터 출처 목록
- 판단 결과 카드: 결론, 신뢰도 점수, 근거 요약, 권장 조치

**AI Agent 응답 형식 (표준)**
```
[판단 결론]: 합격 / 조건부 합격 / 불합격 / 추가 검토 필요
[신뢰도]: 85% (0~100%)
[근거 요약]:
  1. 성분 분석: C=0.42% (기준 0.38~0.45%) - 적합
  2. 과거 이력: 동일 공급사 동일 강종 최근 12개월 합격률 94%
  3. 유사 제품 실적: 동일 강종으로 제조된 LOT 87건 중 불합격 3건 (3.4%)
[권장 조치]: 일반 검수 절차 진행
[참조 데이터]: Heat No. HT12345, 공급사 A사 이력 (2024.01~2026.05)
```

#### 비즈니스 로직

**AI Agent 판단 로직 (원료 적합성 판단)**

1. 성분 분석 결과 vs. 제품 강종 규격 비교 (규칙 기반 1차 필터)
2. 동일 공급사·강종의 과거 합격률 조회 (통계 기반)
3. 유사 성분 범위의 과거 LOT 결과 조회 (유사도 기반 검색)
4. 종합 판단 점수 = 규격 적합도 × 0.5 + 과거 실적 점수 × 0.3 + 유사 LOT 성공률 × 0.2
5. 점수 ≥ 80 → 합격 권고, 60~79 → 조건부 합격, < 60 → 불합격 권고

**신뢰도 산출 기준**
```
신뢰도 = 참조 데이터 충분성 점수 × 데이터 일관성 점수
참조 데이터 충분성: 유사 이력 건수 기반 (0건=20%, 1~5건=50%, 6~20건=75%, 21건+=90%)
데이터 일관성: 참조 데이터 내 합격률 분산 기반 (분산 낮을수록 신뢰도 높음)
신뢰도 < 50% 시 → "데이터 부족으로 판단 신뢰도 낮음. 추가 검토 권고" 메시지 필수 표시
```

**배합 조건 추천 로직**
- 목표 제품 강종 규격의 중간값에 근접하도록 여러 Heat No.의 혼합 비율 최적화
- 제약 조건: 재고 수량, Heat No.별 가용 비율
- 출력: 추천 배합 비율 + 혼합 후 예상 성분 범위 + 신뢰도

**지원 자연어 질의 유형**
- "Heat No. HT12345가 SS400 제품에 적합한가?"
- "A공급사의 최근 6개월 품질은 어떤가?"
- "현재 재고 중 SM45C 제품 제조에 가장 적합한 원료는?"
- "LOT 2605-HT12345-01의 공정 현황은?"
- "지난 달 불합격 원료의 주요 원인은?"

#### 데이터 입출력 정의

**입력 데이터**
- 사용자 자연어 질의 (텍스트)
- 컨텍스트: 현재 조회 중인 Heat No., LOT, 공급사 (선택적)
- 내부 DB: 입고 데이터, 품질 이력, 공정 MES, 검사 DB (RAG 검색)

**출력 데이터**
- 구조화된 판단 결과 카드 (결론, 신뢰도, 근거, 권장 조치)
- 참조 데이터 목록 (출처 투명성 확보)
- 대화 이력 저장 (감사 목적)

**연동 시스템**
- 내부 통합 DB (RAG 검색 엔진)
- LLM API (자연어 이해·생성)
- 알림 서비스 (판단 결과를 담당자에게 공유 가능)

#### 수용 기준 (Acceptance Criteria)

1. 모든 AI 판단 결과에는 신뢰도(%) 수치가 반드시 포함되며, 신뢰도 50% 미만인 경우 "데이터 부족 - 추가 검토 필요" 경고 메시지가 표시된다.
2. 자연어 질의 입력 후 판단 결과가 10초 이내에 반환되어야 한다.
3. AI 판단 근거에는 참조한 데이터 출처(Heat No., 기간, 건수)가 구체적으로 명시된다.
4. 배합 조건 추천 결과는 추천 비율, 혼합 후 예상 성분 범위, 신뢰도를 포함한 구조화된 카드 형식으로 표시된다.
5. 사용자가 AI 판단에 동의·반대 피드백을 입력할 수 있으며, 피드백이 모델 재학습 파이프라인에 연계된다.
6. 대화 이력이 사용자별로 저장되고, 이전 대화 컨텍스트를 유지한 연속 질의가 가능하다.

## 5. 전체 우선순위 요약 (MoSCoW)

### Must Have (이번 이터레이션 필수)

- AI 대시보드: 실시간 공정 흐름 맵, KPI 카드, 병목 알림, 품질 KPI 및 기계적 성질 조회, 설비 실시간 센서 알림, 출하 예정 리스트
- 입고배합관리: Heat No. 입고 등록, 성분 합부 판정, LOT 자동 채번, 원자재 이력 역추적, 데이터 정합성 검증, 공급사 품질 합격률, AI Agent 적합성 판단 (신뢰도 포함)

### Should Have (일정 허용 시 포함)

- AI 납기 리스크 예측, 설비 AI 위험도 점수, 배합 조건 AI 추천, 공급사 비교 분석, 데이터 품질 모니터링, AI Agent 피드백 수집

### Could Have (다음 이터레이션 검토)

- 모바일 반응형 대시보드, 결함 위치 도면 오버레이, 밀 시트 PDF 파싱 자동 입력, AI 추천 공급사 제안, 피드백 기반 모델 재학습

### Won't Have (현재 범위 외)

- 3D 설비 모델 시각화, 고객 포털 연동 알림, ERP 실시간 양방향 연동 (단방향 수신만 포함)
