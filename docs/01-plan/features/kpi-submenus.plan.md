> **요약**: 사업계획서 p.43 기반 KPI 관리 모듈의 3개 하위메뉴 기능 정의 — 생산성 KPI 조회, 품질 KPI 조회, KPI 관리(목표값 설정/이력 추적)
>

> **작성일**: 2026-05-21
> **최종수정**: 2026-05-21

## 1. 개요

### 배경

사업계획서 p.43에 KPI 관리 모듈의 3개 하위메뉴가 정의되어 있다. 현재 사이드바에 "KPI 관리" 최상위 메뉴는 존재하지만 하위메뉴 구조와 각 KPI 지표의 상세 정의가 미확정 상태이다. 기존 DB 스키마에는 `kpi_daily_snapshots` 및 `kpi_targets` 테이블이 존재하여 이를 기반으로 기능을 구현한다.

### 목적

- KPI 관리 모듈의 3개 하위메뉴를 사업계획서 기준으로 정의하여 개발 범위를 명확히 한다.
- 생산성과 품질 KPI 지표를 자동 산출하여 관리자가 현황을 즉시 파악할 수 있도록 한다.
- KPI 목표값 설정 및 이력 관리 기능을 통해 지속적인 공정 개선 체계를 지원한다.

### 범위

| 항목 | 포함 여부 |
|------|-----------|
| 3개 하위메뉴 UI/UX 요구사항 정의 | 포함 |
| KPI 지표 산출 공식 정의 | 포함 |
| API 엔드포인트 목록 정의 | 포함 |
| KPI 데이터 수집 자동화 파이프라인 | 제외 (데이터관리 별도 Plan) |
| ERP/외부 시스템 KPI 연동 | 제외 (차후 이터레이션) |

## 2. KPI 지표 정의

### 생산성 KPI 지표

| 지표명 | 산출 공식 | 단위 |
|--------|----------|------|
| 생산량 | 완료 작업지시 수량 합계 | 개/톤 |
| 설비가동률 (OEE) | (가동시간 / 계획가동시간) × 100 | % |
| 공정 리드타임 | 작업 완료시각 - 작업 시작시각 (평균) | 시간 |
| 계획 대비 달성률 | (실적 생산량 / 계획 생산량) × 100 | % |

### 품질 KPI 지표

| 지표명 | 산출 공식 | 단위 |
|--------|----------|------|
| 불량률 | (불량 수량 / 전체 생산 수량) × 100 | % |
| 출하 품질 합격률 | (합격 출하 수량 / 전체 출하 수량) × 100 | % |
| 클레임 발생률 | (클레임 건수 / 출하 건수) × 100 | % |
| 재가열률 | (재가열 투입 수량 / 전체 가열 투입 수량) × 100 | % |

## 3. 하위메뉴별 사용자 스토리

### 3-1. 생산성 KPI 조회 (`/kpi/productivity`)

**역할**: 공장장, 생산 관리자, 공정 담당자

> "나는 생산 관리자로서, 오늘/이번 주/이번 달의 생산량, 설비가동률, 공정 리드타임 등 생산성 지표를 한 화면에서 시각적으로 확인하고 싶다."

**수용 기준**
- 생산량, 설비가동률(OEE), 공정 리드타임, 계획 대비 달성률이 카드 형태로 표시된다.
- 조회 기간(일/주/월)을 선택할 수 있다.
- 공정별(단조, 열처리 등) 생산성 지표를 구분하여 조회할 수 있다.
- 목표값 대비 실적을 색상(초과/달성/미달)으로 시각적으로 구분한다.
- 추이 차트(꺾은선 그래프)로 기간별 변화 추이를 확인할 수 있다.

---

### 3-2. 품질 KPI 조회 (`/kpi/quality`)

**역할**: 품질 관리자, 공장장

> "나는 품질 관리자로서, 공정별 불량률, 출하 합격률, 클레임 발생률 등 품질 지표가 자동 산출되어 표시되기를 원하며, 목표값 초과 시 시각적 경고를 받고 싶다."

**수용 기준**
- 불량률, 공정별 불량 유형, 출하 품질 합격률, 클레임 발생률이 자동 산출되어 표시된다.
- 불량 유형은 파레토 차트(상위 유형 우선 표시)로 시각화된다.
- 조회 기간(일/주/월) 및 공정별 필터를 지원한다.
- 목표값 초과 지표는 빨간색 경고 표시가 적용된다.
- 클레임 발생 건의 경우 클릭 시 해당 LOT 추적 화면으로 이동하는 연계 링크가 제공된다.

---

### 3-3. KPI 관리 (`/kpi/management`)

**역할**: 공장장, 시스템 관리자

> "나는 공장장으로서, 각 KPI 지표의 목표값을 설정하고 변경 이력을 추적하며, AI가 제안하는 개선 인사이트를 확인하고 싶다."

**수용 기준**
- KPI 목표값을 공정별, 지표별로 설정(Create), 수정(Update), 삭제(Delete)할 수 있다.
- 목표값 변경 이력(변경 전/후 값, 변경 일시, 변경자)이 기록되어 조회 가능하다.
- 공정별 KPI 항목을 개별적으로 활성화/비활성화할 수 있다.
- AI 기반 개선 인사이트(예: "이번 달 불량률이 목표값을 3회 초과했습니다. 원인 분석을 확인하세요.")가 표시된다.
- 목표값 설정은 공장장 이상 권한으로 제한된다.

## 5. API 엔드포인트 목록

| 메서드 | 경로 | 설명 | 권한 |
|--------|------|------|------|
| GET | `/api/kpi/productivity` | 생산성 KPI 지표 조회 | 인증 사용자 |
| GET | `/api/kpi/productivity?period={day\|week\|month}&process_id={id}` | 기간/공정별 생산성 KPI 필터 | 인증 사용자 |
| GET | `/api/kpi/quality` | 품질 KPI 지표 조회 | 인증 사용자 |
| GET | `/api/kpi/quality?period={day\|week\|month}&process_id={id}` | 기간/공정별 품질 KPI 필터 | 인증 사용자 |
| GET | `/api/kpi/targets` | KPI 목표값 목록 조회 | 인증 사용자 |
| POST | `/api/kpi/targets` | KPI 목표값 생성 | 공장장 이상 |
| PUT | `/api/kpi/targets/{id}` | KPI 목표값 수정 | 공장장 이상 |
| DELETE | `/api/kpi/targets/{id}` | KPI 목표값 삭제 | 공장장 이상 |
| GET | `/api/kpi/targets/{id}/history` | KPI 목표값 변경 이력 조회 | 인증 사용자 |
| GET | `/api/kpi/insights` | AI 기반 KPI 개선 인사이트 조회 | 인증 사용자 |

**기존 연관 테이블**: `kpi_daily_snapshots`, `kpi_targets`

**신규 테이블 (설계 시 고려)**
- `kpi_target_history` — KPI 목표값 변경 이력 (변경 전/후, 변경자, 변경 일시)
- `kpi_definitions` — KPI 지표 정의 및 산출 공식 메타데이터
