## 1. 개요

### 배경

사업계획서 p.43에 AI Agent 관리 모듈의 5개 하위메뉴가 정의되어 있다. 현재 사이드바에 "AI Agent 관리" 최상위 메뉴는 존재하지만 하위메뉴 구조와 각 기능의 상세 요구사항이 미정의 상태이다. 기존 DB 스키마에는 `ai_agent_sessions` 테이블이 존재하며, 이를 기반으로 기능을 확장한다.

### 목적

- AI Agent 관리 모듈의 5개 하위메뉴를 사업계획서 기준으로 정의하여 개발 범위를 명확히 한다.
- 사용자(현장 관리자, 공정 담당자)가 자연어로 MES 데이터를 조회하고 AI 기반 의사결정 지원을 받을 수 있는 인터페이스를 기획한다.
- AI 성능의 지속적 향상을 위한 질문이력 수집 체계를 정의한다.

### 범위

| 항목 | 포함 여부 |
|------|-----------|
| 5개 하위메뉴 UI/UX 요구사항 정의 | 포함 |
| API 엔드포인트 목록 정의 | 포함 |
| AI 모델 학습 파이프라인 설계 | 제외 (AI 서비스 별도 Plan) |
| 알림 발송 채널(SMS, 이메일) 구현 | 제외 (알림설정 Plan에서 별도 정의) |
| AI 답변 정확도 평가 시스템 | 제외 (차후 이터레이션) |

## 2. 하위메뉴별 사용자 스토리

### 2-1. 통합 AI 질의 (`/ai-agent/query`)

**역할**: 현장 관리자, 공정 담당자, 품질 담당자

> "나는 현장 관리자로서, 복잡한 SQL이나 메뉴 탐색 없이 자연어로 '오늘 단조 공정 불량률이 몇 %야?'라고 입력하면 즉시 답변을 받고 싶다."

**수용 기준**
- 사용자가 자연어 텍스트를 입력하면 AI가 답변을 반환한다.
- 생산, 품질, 출하, 설비 등 전 공정 데이터를 질의할 수 있다.
- 답변에는 데이터 출처(공정명, 시간범위)가 포함된다.
- 질의 결과는 텍스트 및 간략 차트로 표시될 수 있다.
- 질의 이력은 자동 저장되어 "사용자 질문이력" 메뉴에서 확인 가능하다.

---

### 2-2. 생산/품질 분석 (`/ai-agent/analysis`)

**역할**: 생산 관리자, 품질 관리자

> "나는 품질 관리자로서, AI가 최근 공정 데이터를 자동 분석하여 문제 발생 패턴과 개선 방향을 요약 리포트로 제공해 주기를 원한다."

**수용 기준**
- AI가 생산량, 불량률, 공정 이상 패턴 등을 자동 분석한 결과를 표시한다.
- 분석 결과에는 문제점 요약과 개선 방향 제안이 포함된다.
- 분석 기간(일/주/월)을 선택할 수 있다.
- 분석 리포트는 공정별(단조, 열처리 등)로 구분하여 조회 가능하다.
- 각 AI 분석 결과에는 신뢰도 점수(Confidence Score, 0~100%)가 표시된다.

---

### 2-3. 의사결정 지원 (`/ai-agent/decision`)

**역할**: 공장장, 생산 관리자

> "나는 공장장으로서, 납기 지연 위험 LOT 또는 품질 이상이 우려되는 공정에 대해 AI가 구체적인 조치 옵션을 추천해 주기를 원한다."

**수용 기준**
- 현재 진행 중인 공정/LOT 현황 기반으로 AI가 의사결정 추천 항목을 제공한다.
- 추천 항목별로 근거 데이터(관련 KPI, 이상 지표)가 함께 표시된다.
- 추천 조치에 대해 사용자가 "수용/거절/보류" 응답을 남길 수 있다.
- 응답 이력은 AI 학습 피드백 데이터로 저장된다.
- 각 추천에 신뢰도 점수가 표시된다.

---

### 2-4. 알림 및 추천 (`/ai-agent/alerts`)

**역할**: 공정 담당자, 품질 담당자, 관리자

> "나는 공정 담당자로서, 설비 이상이나 품질 기준 초과 상황이 발생하면 즉시 알림을 받고, AI가 제안하는 개선 조건을 함께 확인하고 싶다."

**수용 기준**
- 이상 감지 시 발생한 알림 목록이 시간순으로 표시된다.
- 각 알림에는 이상 유형, 발생 공정/설비, 발생 시각이 포함된다.
- 알림과 함께 AI가 제안하는 개선 조건(예: 가열 온도 조정, LOT 재검사)이 표시된다.
- 알림 상태(미확인/확인/조치완료)를 업데이트할 수 있다.
- 알림 필터(공정별, 심각도별, 날짜별)를 지원한다.

---

### 2-5. 사용자 질문이력 (`/ai-agent/history`)

**역할**: 시스템 관리자, AI 운영 담당자

> "나는 시스템 관리자로서, 사용자들이 AI에 질의한 내용과 AI의 답변을 열람하여 자주 묻는 질문 패턴을 파악하고, AI 성능 개선에 활용하고 싶다."

**수용 기준**
- 전체 사용자의 질의-응답 이력이 목록으로 표시된다.
- 사용자별, 날짜별, 키워드별 필터링이 가능하다.
- 각 이력에는 질의 내용, AI 응답, 응답 신뢰도, 사용자 피드백(좋음/나쁨)이 포함된다.
- 자주 등장하는 질의 키워드 통계를 요약 차트로 확인할 수 있다.
- 개인정보 보호를 위해 시스템 관리자 권한으로만 접근 가능하다.

## 3. 기능 요구사항

### Must Have

| ID | 하위메뉴 | 요구사항 |
|----|---------|---------|
| FR-01 | 통합 AI 질의 | 자연어 텍스트 입력 인터페이스가 제공되어야 한다. |
| FR-02 | 통합 AI 질의 | 생산/품질/출하/설비 전 공정 데이터를 질의 대상으로 지원해야 한다. |
| FR-03 | 통합 AI 질의 | 질의 결과에 데이터 출처(공정명, 시간범위)가 포함되어야 한다. |
| FR-04 | 생산/품질 분석 | AI 자동 분석 결과(문제점 + 개선 방향)가 표시되어야 한다. |
| FR-05 | 생산/품질 분석 | 모든 AI 분석 결과에 신뢰도 점수(Confidence Score)가 표시되어야 한다. |
| FR-06 | 의사결정 지원 | 현재 공정/LOT 기반 AI 추천 항목이 근거 데이터와 함께 표시되어야 한다. |
| FR-07 | 알림 및 추천 | 이상 발생 알림 목록이 시간순으로 표시되어야 한다. |
| FR-08 | 알림 및 추천 | 각 알림에 AI 개선 조건 추천이 함께 표시되어야 한다. |
| FR-09 | 사용자 질문이력 | 질의-응답 이력 목록이 조회되어야 한다. |
| FR-10 | 사용자 질문이력 | 시스템 관리자 권한으로만 전체 이력에 접근 가능해야 한다. |

## 4. API 엔드포인트 목록

| 메서드 | 경로 | 설명 | 권한 |
|--------|------|------|------|
| POST | `/api/ai-agent/query` | 자연어 질의 요청 및 AI 응답 반환 | 인증 사용자 |
| GET | `/api/ai-agent/analysis` | AI 자동 분석 리포트 조회 | 인증 사용자 |
| GET | `/api/ai-agent/analysis?period={day\|week\|month}&process={id}` | 기간/공정별 분석 필터 | 인증 사용자 |
| GET | `/api/ai-agent/decisions` | 의사결정 추천 항목 목록 조회 | 인증 사용자 |
| PATCH | `/api/ai-agent/decisions/{id}/response` | 추천 항목 응답(수용/거절/보류) 저장 | 인증 사용자 |
| GET | `/api/ai-agent/alerts` | 알림 및 추천 목록 조회 | 인증 사용자 |
| PATCH | `/api/ai-agent/alerts/{id}/status` | 알림 상태 업데이트 | 인증 사용자 |
| GET | `/api/ai-agent/history` | 전체 사용자 질문이력 조회 | 시스템 관리자 |
| GET | `/api/ai-agent/history?user_id={id}&keyword={kw}&from={date}&to={date}` | 질문이력 필터 조회 | 시스템 관리자 |

**기존 연관 테이블**: `ai_agent_sessions`

**신규 테이블 (설계 시 고려)**
- `ai_decisions` — 의사결정 추천 항목 및 사용자 응답 이력
- `ai_alerts` — AI 생성 알림 및 개선 추천 이력
