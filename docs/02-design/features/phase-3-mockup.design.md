# Design — phase-3-mockup

> Pipeline Phase 3 | UI/UX 목업 설계

## 기술 스택 결정

| 항목 | 선택 | 이유 |
|------|------|------|
| 파일 형태 | 단일 HTML (standalone) | 서버 없이 브라우저로 즉시 확인 가능 |
| CSS | Tailwind CSS CDN | 빠른 레이아웃, 기존 파일과 동일 |
| 차트 | Chart.js 4.x CDN | 기존 파일과 동일 |
| 트리 시각화 | CSS Flex + SVG 커넥터 | 외부 라이브러리 없이 LOT 계보 표현 |
| 아이콘 | Lucide Icons CDN | 기존 파일과 동일 |

## 파일별 화면 설계

### 04-forging-heattreat.html

**탭 1 — 단조공정**
```
[필터: 날짜범위 | 설비 | 상태] [새 워크오더]

워크오더 테이블:
| WO번호 | LOT | 소재규격 | 목표중량 | 압하량 | 단조비 | 설비 | 상태 | 시작~완료 |

실시간 모니터링 패널 (2열):
┌─────────────────────────┐  ┌─────────────────────────┐
│ PRESS-01                │  │ PRESS-02                │
│ [압력 게이지 반원형]      │  │ [압력 게이지 반원형]      │
│ 현재: 2,850 ton          │  │ 현재: 3,100 ton          │
│ 온도: 1,180°C           │  │ 온도: 1,150°C           │
│ 타격수: 42회             │  │ 타격수: 38회             │
└─────────────────────────┘  └─────────────────────────┘

하단 차트 (2열):
- 압력-온도 상관 산점도 (Chart.js scatter)
- 시간별 생산량 막대 차트
```

**탭 2 — 열처리공정**
```
배치 목록 테이블:
| 배치번호 | LOT | 열처리종류(QT/Norm/Ann) | 노 | 목표온도 | 유지시간 | 상태 |

노 현황 패널 (2열):
┌─────────────────────────┐  ┌─────────────────────────┐
│ HT-01 (담금질로)         │  │ HT-02 (뜨임로)           │
│ [온도 게이지]             │  │ [온도 게이지]             │
│ 현재: 870°C             │  │ 현재: 580°C             │
│ 목표: 880°C             │  │ 목표: 580°C             │
│ 잔여: 1h 23m            │  │ 잔여: 45m              │
└─────────────────────────┘  └─────────────────────────┘

온도 프로파일 차트 (시간 흐름 선 차트):
- 목표곡선(점선) vs 실측곡선(실선)
- X: 경과시간(h), Y: 온도(°C)
- 구간 표시: 승온 / 유지 / 냉각
```

### 05-lot-traceability.html

```

    │

    │

  │             │
```
