**Why:** 공정 데이터 통합 관리, AI 기반 의사결정 지원 체계 구축
**How to apply:** 모든 기능은 Heat No. / LOT 번호 기준 추적성을 기본으로 설계할 것.

## 모듈 구성 (기획서 작성 완료)
- M5: 공정관리 (공정실적, 모니터링, 작업조건, 이력조회, 데이터분석)
- M6: 사용자/시스템관리 (RBAC, 로그, 알림, 시스템설정)
- M7: 기준정보관리 (품질기준, SOP, 코드관리)
- M8: 데이터관리 (통합관리, 조회, 시각화, 다운로드, AI학습데이터)
- M9: AI Agent 통합관리 (자연어질의, 분석, 의사결정, 알림, 이력)
- M10: KPI관리 (생산성KPI, 품질KPI, 목표관리)

## 태웅 특화 KPI
- OEE = 가용성 × 성능률 × 품질률 (목표 ≥ 75%)
- 납기 준수율 (목표 ≥ 95%)
- 공정 불량률 (목표 ≤ 3%)
- 재가열률 = 재가열 건수 / 전체 가열 건수 × 100 (목표 ≤ 2%)
- 검사 합격률 (목표 ≥ 97%)
